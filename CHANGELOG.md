# Changelog

## [0.5.0] - 2026-01-28

### Added
- Страница настроек пользователя для настройки Telegram-уведомлений
- Интеграция с Telegram Bot API для автоматической отправки AI-подсказок
- Умное форматирование подсказок через LLM перед отправкой в Telegram
- Middleware для централизованной аутентификации API routes
- Валидация переменных окружения Supabase при старте приложения

### Changed
- Унифицирован формат ответов API (`ApiResponse<T>`)
- Централизована обработка ошибок через класс `ApiError` и middleware
- Улучшена безопасность: скрыты внутренние детали системы от клиента в ошибках API
- Обновлена главная страница с описанием всех возможностей проекта
- Обновлена документация в README.md

### Fixed
- Исправлена обработка ответов API в клиентском коде после рефакторинга
- Удалены избыточные логи из клиентских компонентов (риск утечки данных)

## [0.4.0] - 2026-01-24

### Added
- Поддержка локализации на 7 языках (ru, en, es, kk, zh, ko, ja) с использованием next-intl
- Локализация дат и форматирование по локали пользователя
- Переключатель языка в интерфейсе
- Автоматический деплой через GitHub Actions для ветки `dev`

### Changed
- Обновлен Next.js до версии 16.1.4
- Обновлен Node.js до версии 22

### Fixed
- Исправлена проблема бесконечных запросов на странице `/users`
- Исправлены переводы месяцев на казахском языке
- Исправлены проблемы со сборкой при добавлении локализации

## [0.3.0] - 2025-12-24

### Added
- AI-подсказки для игры 15-puzzle через VseGPT API
- Сохранение и загрузка состояния игр в Supabase
- Автоматический деплой через GitHub Actions для ветки `master`

### Fixed
- Множественные исправления настройки автодеплоя

## [0.2.0] - 2025-12-22

### Added
- Темная тема с сохранением выбора в cookies
- Сброс пароля через email
- Защита страниц через HOC `withAuth`
- Страница списка пользователей системы

### Changed
- Улучшена мобильная версия игры 15-puzzle
- Оптимизированы стили главной страницы
- Стили игры 15-puzzle вынесены в CSS модуль

## [0.1.0] - 2025-12-18

### Added
- Базовая структура проекта на Next.js с TypeScript
- Авторизация через Supabase
- Drag & Drop игра
- Игра 15-puzzle
- Страница продуктов с динамическими маршрутами
- Material-UI компоненты
